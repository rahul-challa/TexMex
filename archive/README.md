# Archive

Historical documentation and scripts that are no longer part of the active workflow, kept for reference rather than deleted outright.

- `IMPROVEMENTS_SUMMARY.md` - point-in-time summary of the v0.0.5 feature work
- `PUBLISH_GUIDE.md`, `PUBLISH_WORKFLOW.md`, `PUBLISH_CHECKLIST.txt` - earlier publishing walkthroughs, superseded by [`PUBLISHING.md`](../PUBLISHING.md) at the project root
- `QUICK_START.md`, `SETUP_GUIDE.md` - earlier standalone setup guides, superseded by [`README.md`](../README.md)
- `github-release.ps1`, `publish.ps1` - release automation scripts written for a specific past release (hardcoded version/repo values); superseded by the plain `gh`/`vsce` commands in `PUBLISHING.md`

These files are frozen as-is and may reference old version numbers, settings, or URLs. Don't treat them as current instructions.
